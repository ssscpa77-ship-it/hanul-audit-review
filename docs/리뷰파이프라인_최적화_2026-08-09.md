# 리뷰 파이프라인 최적화 (2026-08-09, v0.9.3)

목표: **가장 짧은 시간에 실무적으로 유효한 리뷰노트**를 낸다.  
품질 앵커(자가진단 G0~G4·감리 전수·필수절차 카탈로그)는 유지하고, 중복·캐시 파괴·불필요 RAG만 제거한다.

## 소유권 (중복 금지)

| 작업 | 소유 | after_L1에서 |
|------|------|--------------|
| 4대 중점 G0~G4 | L1 `focus_selfcheck` | FA-4 전수 금지 |
| 감리지적 전수 | L1 `enforcement_review` | FA-4 red-flag만 |
| 합계 재계산 | L1 (표 상한 24) | FA-1 생략 |
| 필수절차 카탈로그 | FA-3 | 계정 존재 시만 |
| 계정 고유 함정 | AA (전문 로직) | 제네릭은 비전문 계정만 |

## 적용한 단축

1. hot path `cache_clear()` 제거 (focus/fss/qc/UI) — xlsx 반복 로드 방지  
2. `prune_documented` 1회로 통합; `focus_gate` 노트는 구엔진으로 재평가하지 않음  
3. 문서 단위 캐시: `document_accounts`, `account_sheet_text`  
4. L1 합계검증: 거대표 스킵·우선순위·최대 24표  
5. AA: 전문 에이전트 있으면 카탈로그 부분충족 스캔 생략 (FA-3와 중복)  
6. `_attach_references`: 사례·근거가 이미 있는 감리/자가진단 노트는 KB 재검색 생략  
7. AI: 4대 중점 제목 블록을 시트 루프마다 만들지 않고 1회 재사용  
8. Conductor after_L1: FA-1/FA-2/FA-4 전수 생략 (기존)

## 쓰지 않는 것 (품질)

- `focus_selfcheck` / 220단계 / 감리 체크리스트 전수  
- FA-3 카탈로그 Pass/Fail  
- note_merge의 focus·enforcement 보호  

## 운영 팁

- 빠른 검토: **AI OFF** (규칙+멀티에이전트만)  
- AI ON은 시트당 API — 상한 12시트  
- KB 구조인식 청킹 재색인은 별도 Mac 작업(`build_index.py --reset`)
