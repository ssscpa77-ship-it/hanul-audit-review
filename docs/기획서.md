# 「자가 심리 에이전트」 제품 기획서

> 버전: MVP 0.1 · 작성일: 2025-06-03  
> 목적: 회계법인 QRM 제출 전 감사조서 자가검토

---

## 1. 한 줄 정의

회계사가 작성한 감사조서를 QRM 제출 전 AI·규칙엔진으로 자가검토하여, 절차 누락·계산오류·증빙 미비·감리 리스크를 사전에 적발하고 **출처가 명확한 리뷰노트**를 생성하는 시스템.

---

## 2. 핵심 원칙

1. **AI 환각 금지**: 근거조문·감리지적 번호는 검증된 DB(RAG)에서만 인용. 미확인 시 "근거 미확인" 표시.
2. **예방적 설계**: 금감원·한국회계기준원 질의회신·감리지적·연도별 **중점감리사항** 반영.
3. **보조 도구**: 최종 책임은 담당 회계사. UI에 명시.
4. **데이터 보안**: 조서는 법인 전용 클라우드(Azure OpenAI 등, 데이터 미학습 계약) 또는 온프레미스.

---

## 3. 사용자·시나리오

| 역할 | 행위 |
|------|------|
| 담당 회계사 | 조서 업로드 → 자가검토 실행 → 대시보드 확인 → 수정 → 재검토 |
| 인차지/파트너 | 동일 (2차 확인) |

```
접속 → 기본정보 입력 → 조서 업로드 → 검토 실행
  → 대시보드(중요도순) + 중점감리 섹션 → 엑셀 다운로드 → 수정 → 재업로드
```

---

## 4. 기능 명세

### 4.1 조서 업로드·파싱
- PDF, Excel, Word (한글은 PDF 변환 권장)
- 표·금액·계정 추출

### 4.2 검토 엔진 (4레이어)

| 레이어 | 내용 | 방식 |
|--------|------|------|
| ① 형식·완전성 | 필수항목·서명·날짜 | 규칙 |
| ② 계산 검증 | 합계·교차합·전기대비 | 코드(pandas) |
| ③ 증빙·절차 | 첨부·입회·확인 | 규칙 + AI |
| ④ 기준·감리 | 기준 위반·유사 지적 | AI + RAG |

### 4.3 리뷰노트 필드
- 중요도(상/중/하), 흠결, 지적사유, **관련근거(출처)**, To-Be, 조서참조

### 4.4 대시보드
- 회사명·기준·조서·계정, KPI, 중요도순 카드, **중점감리 전용 섹션**, 엑셀 다운로드

### 4.5 법인 DB 연동 (RAG)
- 기준서·질의회신·감리지적·과거 조서 → 벡터DB 색인 → 검색·인용
